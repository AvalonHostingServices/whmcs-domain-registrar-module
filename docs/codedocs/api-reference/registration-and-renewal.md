---
title: "Registration and Renewal"
description: "Registrar callbacks for registration, renewal, delete requests, transfers, and transfer-tag changes."
---

These callbacks are defined in `modules/registrars/domain_reseller_registrar/domain_reseller_registrar.php`. Each function is a WHMCS public entrypoint discovered by name.

## `domain_reseller_registrar_RegisterDomain`

```php
function domain_reseller_registrar_RegisterDomain(array $params): array
```

Creates a provider payload for a new registration, including feature flags and nested contact sections.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `params` | `array` | — | WHMCS registrar params for the order, contacts, module config, and enabled add-ons. |

Returns:

```php
['success' => true]
```

or

```php
['error' => 'Registration failed']
```

Example:

```php
<?php

// Effective provider action generated by the module:
$action = 'RegisterDomain';
```

## `domain_reseller_registrar_RenewDomain`

```php
function domain_reseller_registrar_RenewDomain(array $params): array
```

Sends `domainid`, `domainname`, and `regperiod` to the `RenewDomain` provider action.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `params` | `array` | — | WHMCS domain context and module config. |

Returns `['success' => true]` on success or `['error' => ...]` on failure.

Example:

```php
<?php

$providerPayload = [
    'domainid' => 123,
    'domainname' => 'example.com',
    'regperiod' => 1,
];
```

## `domain_reseller_registrar_RequestDelete`

```php
function domain_reseller_registrar_RequestDelete(array $params): array
```

Submits a delete request upstream using `domainid` and `domainname`.

| Parameter | Type | Default | Description |

Returns `['success' => true]` or `['error' => ...]`.

Example:

```php

$providerPayload = [
    'domainid' => 123,

```

## `domain_reseller_registrar_TransferDomain`

```php
function domain_reseller_registrar_TransferDomain(array $params): array
```

Transfers a domain using the EPP code, filtered nameserver list, feature flags, and nested contact data.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `params` | `array` | — | WHMCS transfer data including `eppcode`, `ns1` through `ns5`, contacts, and module config. |

Returns `['success' => true]` or `['error' => ...]`.

Example:

```php
<?php

$providerPayload = [
    'domainid' => 456,
    'domainname' => 'example.net',
    'nameservers' => ['ns1.provider.net', 'ns2.provider.net'],
    'eppcode' => 'AUTH-ABC-123',
    'regperiod' => 1,
];
```

## `domain_reseller_registrar_ReleaseDomain`

```php
function domain_reseller_registrar_ReleaseDomain(array $params): array
```

Changes the registry transfer tag by sending `transfertag` upstream as `newtag`.

| Parameter | Type | Default | Description |
|-----------|------|---------|-------------|
| `params` | `array` | — | WHMCS params containing `transfertag`, domain context, and module config. |

Returns `['success' => true]` or `['error' => ...]`.

Example:

```php
<?php

$providerPayload = [
    'domainid' => 789,
    'domainname' => 'example.uk',
    'newtag' => 'NEW-TAG',
];
```

## Notes

- Source file: `modules/registrars/domain_reseller_registrar/domain_reseller_registrar.php`
- `RegisterDomain()` and `TransferDomain()` both pass the full `$params` array as the `registrant` contact.
- `TransferDomain()` filters empty nameserver values with `array_filter()`.
